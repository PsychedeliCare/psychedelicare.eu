# Contributing to psychedelicare.eu

Thank you for your interest in helping improve this site.

We are still actively working on the website: fixing content, refining layout and accessibility, and importing translations from the legacy WordPress site. The project is evolving, and your help is welcome.

## How to contribute

- **Issues** — Report bugs, broken links, unclear copy, missing translations, or suggest improvements. Please include the page URL and locale when relevant.
- **Pull requests** — Small, focused changes are easiest to review. For larger work, open an issue first so we can align on scope.

Browse [open issues](https://github.com/psychedelicare/psychedelicare.eu/issues) or [start a new one](https://github.com/psychedelicare/psychedelicare.eu/issues/new/choose).

## Development

See [README.md](./README.md) for setup (`pnpm install`, `pnpm dev`, `pnpm build`).

Content lives in `src/content/pages/` as MDX files, organized by slug and locale.
