# Glossary (Ελληνικά)

Common PsychedeliCare terms for translators and reviewers. Reviewers can update preferred terms as language teams make final decisions.

| English source term | Preferred Greek term | Avoid / ambiguity | Usage note |
| --- | --- | --- | --- |
| PsychedeliCare | PsychedeliCare | μετάφραση του ονόματος | Διατηρείται ως εμπορική/οργανωτική ονομασία. |
| psychedelic care | ψυχεδελική φροντίδα | πλαίσιο μόνο ψυχαγωγικής χρήσης | Ευρύτερη φροντίδα, υποστήριξη, εκπαίδευση, ένταξη και πολιτική. |
| psychedelic-assisted therapy / PAT | θεραπεία υποβοηθούμενη από ψυχεδελικά (PAT) | ψυχεδελική θεραπεία χωρίς πλαίσιο | Επαγγελματική θεραπεία με προετοιμασία, συνεδρία και ένταξη. |
| European Citizens’ Initiative / ECI | Ευρωπαϊκή Πρωτοβουλία Πολιτών (ECI) | απλή αναφορά/υπογραφή | Επίσημο δημοκρατικό εργαλείο της ΕΕ. |
| mental health care | φροντίδα ψυχικής υγείας | μόνο θεραπεία ασθένειας | Περιλαμβάνει πρόληψη, φροντίδα, ευεξία και υποστήριξη. |
| substance / medicine | ψυχεδελική ουσία· φάρμακο σε κλινικό πλαίσιο | «ναρκωτικό» ως προεπιλογή | Ουδέτερος όρος «ουσία»· «φάρμακο» μόνο σε θεραπευτικό πλαίσιο. |
| set and setting | set και setting | μόνο περιβάλλον | Set = νοοτροπία· setting = φυσικό/κοινωνικό πλαίσιο. |
| integration | ένταξη / ενσωμάτωση εμπειρίας | αφομοίωση | Επεξεργασία και εφαρμογή των εμπειριών μετά. |
| harm reduction | μείωση βλάβης | εξάλειψη κινδύνου | Πρακτική μείωση κινδύνων, όχι μηδενικός κίνδυνος. |
| decriminalisation / legalisation | αποποινικοποίηση / νομιμοποίηση | εναλλάξ χρήση | Η αποποινικοποίηση μειώνει ποινές· η νομιμοποίηση ρυθμίζει νόμιμη πρόσβαση. |
| compassionate use | παρηγορητική/κατ’ εξαίρεση χρήση | φιλανθρωπική πρόσβαση | Ιατρική εξαίρεση για σοβαρή ανεκπλήρωτη ανάγκη. |
| lived experience | βιωμένη εμπειρία | ανεκδοτολογία | Γνώση πρώτου προσώπου για φροντίδα και πολιτική. |
| peer support | υποστήριξη ομοτίμων | θεραπεία | Αμοιβαία υποστήριξη από άτομα με σχετική εμπειρία. |
| wellbeing | ευεξία | wellness marketing | Ολιστική ψυχική, σωματική, κοινωνική και οικολογική υγεία. |
| stigma | στίγμα | μόνο ντροπή | Κοινωνική και δομική απαξίωση. |
| nEUsletter | nEUsletter | newsletter | Διατήρηση της γραφής της καμπάνιας. |
