# Glossary (Deutsch)

Common PsychedeliCare terms for translators and reviewers. Reviewers can update preferred terms as language teams make final decisions.

| English source term | Preferred German term | Avoid / ambiguity | Usage note |
| --- | --- | --- | --- |
| PsychedeliCare | PsychedeliCare | Markenname übersetzen | Marke unverändert lassen. |
| psychedelic care | psychedelische Versorgung | Freizeitkonsum-Framing | Umfasst Versorgung, Unterstützung, Bildung, Integration und Politik. |
| psychedelic-assisted therapy / PAT | psychedelisch assistierte Therapie (PAT) | psychedelische Therapie ohne Kontext | Für professionell begleitete Therapie mit Vorbereitung, Sitzung und Integration. |
| European Citizens’ Initiative / ECI | Europäische Bürgerinitiative (EBI) | Petition | Formales demokratisches Instrument der EU. |
| mental health care | psychische Gesundheitsversorgung | nur Behandlung psychischer Erkrankungen | Umfasst Prävention, Versorgung, Wohlbefinden und Unterstützung. |
| substance / medicine | psychedelische Substanz; Medizin im klinischen Kontext | Droge als Standardbegriff | Neutral „Substanz“ verwenden; „Medizin“ im therapeutischen Kontext. |
| set and setting | Set und Setting | nur Umgebung | Set = innere Haltung; Setting = physischer/sozialer Kontext. |
| integration | Integration | Eingliederung | Verarbeitung und Anwendung von Einsichten nach einer Erfahrung. |
| harm reduction | Schadensminderung | Risikofreiheit | Praktische Verringerung von Risiken, keine Risikofreiheit. |
| decriminalisation / legalisation | Entkriminalisierung / Legalisierung | austauschbare Verwendung | Entkriminalisierung reduziert Strafen; Legalisierung schafft regulierten Zugang. |
| compassionate use | Härtefallprogramm / Compassionate Use | Wohltätigkeitszugang | Medizinischer Ausnahmezugang bei ungedecktem Bedarf. |
| lived experience | gelebte Erfahrung | Anekdote | Wissen aus erster Hand für Versorgung und Politik. |
| peer support | Peer-Unterstützung | Therapie | Gegenseitige Unterstützung durch Menschen mit relevanter Erfahrung. |
| wellbeing | Wohlbefinden | Wellness-Marketing | Ganzheitliche psychische, körperliche, soziale und ökologische Gesundheit. |
| stigma | Stigma | nur Scham | Soziale und strukturelle Abwertung. |
| nEUsletter | nEUsletter | Newsletter | Kampagnenschreibweise beibehalten. |
