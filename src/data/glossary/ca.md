# Glossary (Català)

Common PsychedeliCare terms for translators and reviewers. Reviewers can update preferred terms as language teams make final decisions.

| English source term | Preferred Catalan term | Avoid / ambiguity | Usage note |
| --- | --- | --- | --- |
| PsychedeliCare | PsychedeliCare | traduir la marca | Mantenir la marca sense traduir. |
| psychedelic care | cura psicodèlica | marc només recreatiu | Cura, suport, educació, integració i política. |
| psychedelic-assisted therapy / PAT | teràpia assistida amb psicodèlics (PAT) | teràpia psicodèlica sense context | Teràpia professional amb preparació, sessió i integració. |
| European Citizens’ Initiative / ECI | Iniciativa Ciutadana Europea (ICE) | petició | Instrument democràtic formal de la UE. |
| mental health care | atenció a la salut mental | només tractament de malaltia | Inclou prevenció, cura, benestar i suport. |
| substance / medicine | substància psicodèlica; medicina en context clínic | droga com a terme per defecte | Usar “substància” de manera neutral. |
| set and setting | set i setting | només entorn | Set = estat mental; setting = context físic/social. |
| integration | integració | assimilació | Processar i aplicar aprenentatges després de l’experiència. |
| harm reduction | reducció de danys | absència de risc | Reducció pràctica de riscos. |
| decriminalisation / legalisation | despenalització / legalització | ús com a sinònims | La despenalització redueix sancions; la legalització regula l’accés. |
| compassionate use | ús compassiu | accés benèfic | Accés mèdic excepcional per necessitat greu no coberta. |
| treatment-resistant depression | depressió resistent al tractament | depressió incurable | Depressió que no respon adequadament als tractaments estàndard. |
| lived experience | experiència viscuda | anècdota | Coneixement en primera persona per a la cura i la política. |
| peer support | suport entre iguals | teràpia | Suport mutu entre persones amb experiència rellevant. |
| wellbeing | benestar | màrqueting wellness | Salut mental, física, social i ecològica integral. |
| stigma | estigma | només vergonya | Descrèdit social i estructural. |
| nEUsletter | nEUsletter | butlletí | Mantenir la grafia de campanya. |
