# Glossary (Polski)

Common PsychedeliCare terms for translators and reviewers. Reviewers can update preferred terms as language teams make final decisions.

| English source term | Preferred Polish term | Avoid / ambiguity | Usage note |
| --- | --- | --- | --- |
| PsychedeliCare | PsychedeliCare | tłumaczenie marki | Nazwę pozostawić bez zmian. |
| psychedelic care | opieka psychodeliczna | wyłącznie rekreacyjny kontekst | Opieka, wsparcie, edukacja, integracja i polityka. |
| psychedelic-assisted therapy / PAT | terapia wspomagana psychodelikami (PAT) | terapia psychodeliczna bez kontekstu | Profesjonalna terapia z przygotowaniem, sesją i integracją. |
| European Citizens’ Initiative / ECI | Europejska inicjatywa obywatelska (EIO) | petycja | Formalny instrument demokratyczny UE. |
| mental health care | opieka nad zdrowiem psychicznym | tylko leczenie chorób | Obejmuje profilaktykę, opiekę, dobrostan i wsparcie. |
| substance / medicine | substancja psychodeliczna; lek w kontekście klinicznym | narkotyk jako domyślny termin | Neutralnie używać “substancja”. |
| set and setting | set i setting | tylko otoczenie | Set = nastawienie; setting = kontekst fizyczny/społeczny. |
| integration | integracja | asymilacja | Przetwarzanie i stosowanie wglądów po doświadczeniu. |
| harm reduction | redukcja szkód | brak ryzyka | Praktyczne ograniczanie ryzyka. |
| decriminalisation / legalisation | dekryminalizacja / legalizacja | używanie zamiennie | Dekryminalizacja ogranicza kary; legalizacja tworzy regulowany dostęp. |
| compassionate use | dostęp w trybie compassionate use | dostęp charytatywny | Wyjątkowy dostęp medyczny przy poważnej niezaspokojonej potrzebie. |
| lived experience | doświadczenie przeżyte | anegdota | Wiedza pierwszoosobowa dla opieki i polityki. |
| peer support | wsparcie rówieśnicze | terapia | Wzajemne wsparcie osób z podobnym doświadczeniem. |
| wellbeing | dobrostan | marketing wellness | Całościowe zdrowie psychiczne, fizyczne, społeczne i ekologiczne. |
| stigma | stygmatyzacja | tylko wstyd | Społeczne i strukturalne dyskredytowanie. |
| nEUsletter | nEUsletter | newsletter | Zachować pisownię kampanii. |
