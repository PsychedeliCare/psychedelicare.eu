# Glossary (Hrvatski)

Common PsychedeliCare terms for translators and reviewers. Reviewers can update preferred terms as language teams make final decisions.

| English source term | Preferred Croatian term | Avoid / ambiguity | Usage note |
| --- | --- | --- | --- |
| PsychedeliCare | PsychedeliCare | prevođenje naziva | Naziv ostaje nepromijenjen. |
| psychedelic care | psihodelična skrb | samo rekreativni okvir | Skrb, podrška, edukacija, integracija i politike. |
| psychedelic-assisted therapy / PAT | psihodelicima potpomognuta terapija (PAT) | psihodelična terapija bez konteksta | Profesionalna terapija s pripremom, seansom i integracijom. |
| European Citizens’ Initiative / ECI | Europska građanska inicijativa (EGI) | peticija | Formalni demokratski instrument EU-a. |
| mental health care | skrb o mentalnom zdravlju | samo liječenje bolesti | Uključuje prevenciju, skrb, dobrobit i podršku. |
| substance / medicine | psihodelična supstanca; lijek u kliničkom kontekstu | droga kao zadani pojam | Neutralno koristiti “supstanca”. |
| set and setting | set i setting | samo okruženje | Set = mentalni sklop; setting = fizički/društveni kontekst. |
| integration | integracija | asimilacija | Obrada i primjena uvida nakon iskustva. |
| harm reduction | smanjenje štete | uklanjanje rizika | Praktično smanjenje rizika. |
| decriminalisation / legalisation | dekriminalizacija / legalizacija | korištenje kao sinonima | Dekriminalizacija smanjuje kazne; legalizacija stvara regulirani pristup. |
| compassionate use | suosjećajna uporaba | dobrotvorni pristup | Izniman medicinski pristup kod ozbiljne potrebe. |
| lived experience | proživljeno iskustvo | anegdota | Znanje iz prve ruke koje informira skrb i politike. |
| peer support | vršnjačka podrška | terapija | Uzajamna podrška osoba s relevantnim iskustvom. |
| wellbeing | dobrobit | wellness marketing | Cjelovito mentalno, fizičko, društveno i ekološko zdravlje. |
| stigma | stigma | samo sram | Društveno i strukturno obezvrjeđivanje. |
| nEUsletter | nEUsletter | bilten | Zadržati kampanjsku grafiju. |
